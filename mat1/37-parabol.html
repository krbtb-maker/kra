AYT Matematik 8. Parabol

İkinci derece fonksiyonun grafiği

f(x) = ax² + bx + c (a ≠ 0) biçimindeki fonksiyonun grafiği paraboldür. x² terimi bulunduğu için doğru değil, kıvrılan bir eğri oluşur. a pozitifse kollar yukarı, a negatifse aşağı açılır.

Grafiğin simetri ekseni iki kökün orta noktasından geçer. Kökler biliniyorsa eksenin x koordinatı köklerin ortalamasıdır; kökler bilinmiyorsa:

Simetri ekseni: x = −b/(2a)
Tepe noktası: (−b/(2a), f(−b/(2a)))

Kökler ve diskriminant

Parabolün x eksenini kestiği noktalar f(x) = 0 denkleminin kökleridir. İkinci derece denklemde Δ = b² − 4ac, kök sayısını gösterir:

  • Δ > 0 ise grafik x eksenini iki noktada keser.
  • Δ = 0 ise x eksenine teğet olur.
  • Δ < 0 ise x eksenini kesmez.

Tepe noktasının ordinatı −Δ/(4a) biçiminde de bulunabilir. Bu değer, parabol yukarı açılıyorsa en küçük; aşağı açılıyorsa en büyük fonksiyon değeridir.

Kareye tamamlama ile tepe noktasını görmek

f(x) = a(x − h)² + k yazımı, tepe noktasını doğrudan (h, k) olarak gösterir. Çünkü (x − h)², x = h'de sıfır olur; o noktadaki fonksiyon değeri k'dir.

f(x) = a(x − h)² + k → tepe noktası (h, k)

Kısa özet

Bu ünite, temel tanımı, işlem mantığını ve soru çözümünün ana fikrini bir arada kullanarak güvenli bir yaklaşım geliştirmeyi hedefler. Soruda verilen bilgiyi doğru okuma, uygun kuralı seçme ve sonucu kontrol etme becerisi burada en kritik aşamadır. Temel kavramları unutmadan, işlem basamaklarını düzenli uygulamak hem hız hem de doğruluk sağlar.

Sık yapılan hatalar

  • Verilen bilgiyi gereksiz yere değiştirerek soru cümlesini bozmamak.
  • İşlem sırasını veya işaret kurallarını karıştırmak.
  • Bulunan sonucu kontrol etmeden doğrudan yazmak.

Örnek sorular

Soru 1. f(x) = x² − 4x + 3 parabolünün simetri ekseni nedir?

Çözümü gösterÇözümü gizle
a = 1, b = −4. x = −b/(2a) = 4/2 = 2.

Soru 2. f(x) = x² − 4x + 3 parabolünün tepe noktası nedir?

Çözümü gösterÇözümü gizle
Simetri ekseni x = 2. f(2) = 4 − 8 + 3 = −1; tepe noktası (2, −1).

Soru 3. y = 2(x − 1)² + 3 parabolünün kolları hangi yöne açılır ve tepe noktası nedir?

Çözümü gösterÇözümü gizle
a = 2 pozitif, kollar yukarı açılır. Tepe noktası (1, 3).

Soru 4. x² + 2x + 5 = 0 denkleminin kaç gerçek kökü vardır?

Çözümü gösterÇözümü gizle
Δ = 2² − 4·1·5 = −16 < 0. Gerçek kök yoktur; parabol x eksenini kesmez.
