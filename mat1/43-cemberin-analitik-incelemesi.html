Çember denklemi nereden gelir?

Çember, bir merkeze eşit uzaklıktaki noktaların kümesidir. Merkez M(a, b), yarıçap r ise çember üzerindeki her P(x, y) için |PM| = r'dir. İki nokta arası uzaklık formülünün karesini almak denklemi verir:

(x − a)² + (y − b)² = r² (standart denklem)

Merkez orijindeyse: x² + y² = r².

Genel denklem

Standart denklem açılınca x² + y² + Dx + Ey + F = 0 biçimine gelir. Tersine bu denklemden merkez ve yarıçap bulunur:

M(−D/2, −E/2), r = ½·√(D² + E² − 4F)

Bir denklemin çember belirtmesi için: x² ve y²'nin katsayıları eşit olmalı, xy terimi bulunmamalı ve D² + E² − 4F > 0 olmalıdır (= 0 ise tek nokta, < 0 ise hiçbir nokta).

Kareye tamamlama ile aynı sonuç bulunur: x² − 6x = (x − 3)² − 9. Bu yöntem formül unutulduğunda hayat kurtarır.

Özel konumlar

  • x eksenine teğet çember: r = |b|. y eksenine teğet: r = |a|. İki eksene de teğet: |a| = |b| = r.
  • Bir P(x₀, y₀) noktasının konumu: (x₀ − a)² + (y₀ − b)² değeri r²'den küçükse içte, eşitse üstte, büyükse dışta.

Doğru ile çemberin konumu

Merkezin doğruya uzaklığı d ile yarıçap karşılaştırılır:

d = |A·a + B·b + C| / √(A² + B²) (doğru: Ax + By + C = 0)

d < rKesen2
d = rTeğet1
d > rDışında0

Aynı sonuç, doğru denklemini çember denkleminde yerine yazıp elde edilen ikinci dereceden denklemin diskriminantından da bulunur (Δ > 0 kesen, Δ = 0 teğet, Δ < 0 kesişmez).

Teğet

Teğet, değme noktasındaki yarıçapa diktir. Çember üzerindeki T(x₁, y₁) noktasındaki teğetin denklemi:

(x₁ − a)(x − a) + (y₁ − b)(y − b) = r²

İki çemberin konumu

Merkezler arası uzaklık d, yarıçaplar r₁ ve r₂ ise: d > r₁ + r₂ ayrık; d = r₁ + r₂ dıştan teğet; |r₁ − r₂| < d < r₁ + r₂ iki noktada kesişir; d = |r₁ − r₂| içten teğet; d < |r₁ − r₂| biri diğerinin içinde.

Kısa özet

Çemberin standart denklemi (x − a)² + (y − b)² = r²'dir; genel denklemde merkez (−D/2, −E/2), yarıçap ½√(D² + E² − 4F)'dir. Doğru–çember konumu merkezin doğruya uzaklığıyla, iki çemberin konumu merkezler arası uzaklıkla belirlenir. Teğet, değme noktasındaki yarıçapa diktir.

Sık yapılan hatalar

  • Merkezi (D/2, E/2) almak; işaretler terstir.
  • (x + 3)² ifadesinde merkezin apsisini +3 sanmak; −3'tür.
  • x² ve y² katsayıları farklı olan denklemleri çember sanmak.
