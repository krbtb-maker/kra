20. İkinci Dereceden Denklemler

← Konu listesi

Genel biçim ve çözüm yolları

ax² + bx + c = 0    (a ≠ 0)

Çözüm demek, denklemi sağlayan x değerlerine (köklere) ulaşmaktır. Üç yol:

  • Çarpanlara ayırma: (x – 2)(x – 3) = 0 ise çarpımın sıfır olması için çarpanlardan biri sıfır olmalıdır: x = 2 veya x = 3.
  • Tam kare tamamlama: (x + 1)² = 4 → x + 1 = ±2.
  • Kök formülü (aşağıda).

Diskriminant ve kök formülü

Δ = b² – 4ac    x₁,₂ = (–b ± √Δ) / (2a)

Formül, denklemi tam kare tamamlama ile genel olarak çözerek elde edilir: ax² + bx + c = 0 → (x + b/2a)² = Δ/4a². Δ karekökün içinde olduğundan kök sayısını belirler:

ΔKökler
Δ > 0İki farklı gerçel kök
Δ = 0Çakışık (çift katlı) kök. Denklem bir tam karedir.
Δ < 0Gerçel kök yok (√ içi negatif)

Kökler toplamı ve çarpımı

Kökleri x₁, x₂ olan monik denklem (x – x₁)(x – x₂) = 0'dır. Açarsak x² – (x₁ + x₂)x + x₁x₂ = 0. Bunu ax² + bx + c = 0 ile karşılaştırınca:

x₁ + x₂ = –b/a    x₁ · x₂ = c/a

Kökleri bilinen denklem de şöyle yazılır: x² – (kökler toplamı)x + (kökler çarpımı) = 0.

Bunlardan türeyen yararlı ifadeler

  • x₁² + x₂² = (x₁ + x₂)² – 2x₁x₂
  • 1/x₁ + 1/x₂ = (x₁ + x₂) / (x₁x₂)

Kökleri tek tek bulmanıza gerek kalmadan, toplam ve çarpımdan bu ifadelere ulaşılır.

Kısa özet

Bu ünite, temel tanımı, işlem mantığını ve soru çözümünün ana fikrini bir arada kullanarak güvenli bir yaklaşım geliştirmeyi hedefler. Soruda verilen bilgiyi doğru okuma, uygun kuralı seçme ve sonucu kontrol etme becerisi burada en kritik aşamadır. Temel kavramları unutmadan, işlem basamaklarını düzenli uygulamak hem hız hem de doğruluk sağlar.

Sık yapılan hatalar

  • Verilen bilgiyi gereksiz yere değiştirerek soru cümlesini bozmamak.
  • İşlem sırasını veya işaret kurallarını karıştırmak.
  • Bulunan sonucu kontrol etmeden doğrudan yazmak.

Örnek sorular

Soru 1. x² – 5x + 6 = 0 denkleminin köklerini bulunuz.

Çözümü gösterÇözümü gizle
(x – 2)(x – 3) = 0 → x = 2 veya x = 3. (Formülle: Δ = 25 – 24 = 1, x = (5 ± 1)/2 ✓.)

Soru 2. x² + 4x + k = 0 denkleminin çakışık iki kökü olması için k kaç olmalıdır?

Çözümü gösterÇözümü gizle
Δ = 0: 16 – 4k = 0 → k = 4. (Denklem (x + 2)² = 0 olur.)

Soru 3. x² – 7x + 10 = 0 denkleminin kökleri x₁ ve x₂ ise x₁² + x₂² kaçtır?

Çözümü gösterÇözümü gizle
Toplam 7, çarpım 10. x₁² + x₂² = 7² – 2·10 = 49 – 20 = 29. (Kökler 2 ve 5: 4 + 25 = 29 ✓.)

Soru 4. Kökleri 2 ve –5 olan, başkatsayısı 1 olan ikinci dereceden denklemi yazınız.

Çözümü gösterÇözümü gizle
Toplam = 2 + (–5) = –3, çarpım = 2·(–5) = –10. Denklem: x² – (–3)x + (–10) = 0 → x² + 3x – 10 = 0.
