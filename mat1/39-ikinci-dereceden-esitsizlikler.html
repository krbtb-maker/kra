AYT Matematik 10. İkinci Dereceden Eşitsizlikler

Ana fikir: parabolün eksenin üstünde mi altında mı olduğu

f(x) = ax² + bx + c ifadesinin işaretini sormak, y = f(x) parabolünün hangi x değerlerinde x ekseninin üstünde (pozitif), hangilerinde altında (negatif) olduğunu sormaktır. Parabol x eksenini köklerde keser; kökler arasında bir tarafta, dışında diğer tarafta kalır. Bu yüzden işaret tablosunun kuralı ezber değil, resimdir.

İşaret tablosu kuralları

DiskriminantKöklerİşaret
Δ > 0İki farklı kök x₁ < x₂Köklerin dışında a'nın işareti, arasında a'nın tersi
Δ = 0Çift katlı kök x₁Kökte sıfır, her yerde a'nın işareti
Δ < 0Gerçek kök yokHer x için a'nın işareti
Akılda tutma yolu: a > 0 ise parabol "gülümser" (kollar yukarı). Kökler arasında eksenin altına iner, dışında üstündedir. a < 0 ise tam tersi.

Çarpım ve bölüm eşitsizlikleri

Birden çok çarpanın işaretini birlikte incelemek için:

1. Her çarpanı sıfır yapan değerleri (kökleri) bul ve sayı doğrusuna sırala.

2. En sağdaki aralığın işareti, x'in en büyük kuvvetli terimlerinin katsayılarının çarpımının işaretidir.

3. Sola doğru her tek katlı kökte işaret değişir, çift katlı kökte değişmez.

4. Paydayı sıfır yapan değerler, eşitsizlik "≥" ya da "≤" olsa bile çözüme alınmaz.

Örnek

(x − 1)(x + 2) / (x − 3) ≥ 0 eşitsizliğinde kökler −2, 1, 3. En sağda işaret +; sonra her kökte değişir: (3, ∞) +, (1, 3) −, (−2, 1) +, (−∞, −2) −. Pay kökleri dahil, payda kökü hariç:

Ç.K. = [−2, 1] ∪ (3, ∞)

Her x için sağlanma

ax² + bx + c > 0 eşitsizliğinin her gerçek x için doğru olması, parabolün tamamen eksenin üstünde olması demektir:

Her x için ax² + bx + c > 0 ⇔ a > 0 ve Δ < 0
Her x için ax² + bx + c < 0 ⇔ a < 0 ve Δ < 0

Köklerin işaretine göre koşullar

x₁ + x₂ = −b/a ve x₁·x₂ = c/a bilgileriyle:

İstenenKoşullar
Zıt işaretli iki kökc/a < 0 (Δ > 0 kendiliğinden sağlanır)
İki pozitif kökΔ > 0, x₁ + x₂ > 0, x₁·x₂ > 0
İki negatif kökΔ > 0, x₁ + x₂ < 0, x₁·x₂ > 0

Eşitsizlik sistemleri

Birden çok eşitsizliğin birlikte sağlanması istenir. Her birinin çözüm kümesi ayrı bulunur ve kesişimleri alınır. Sayı doğrusunda tarama yapmak hata riskini azaltır.

Kısa özet

İkinci dereceden ifadenin işareti, parabolün x eksenine göre konumudur: Δ > 0 ise köklerin dışında a'nın işareti. Çarpım–bölüm eşitsizliklerinde en sağdaki işaret bulunur, tek katlı köklerde işaret değişir; payda kökleri alınmaz. Her x için pozitiflik a > 0 ve Δ < 0 ile sağlanır.

Sık yapılan hatalar

  • Paydayı sıfır yapan değeri "≥" yüzünden çözüme katmak.
  • Çift katlı kökte işaret değiştirmek.
  • Her iki tarafı x içeren bir ifadeyle çarpmak ya da bölmek (ifadenin işareti bilinmediği için yön kontrolsüz değişir).

Örnek sorular

Soru 1. x² − x − 12 ≤ 0 eşitsizliğini sağlayan kaç tam sayı vardır?

Çözümü gösterÇözümü gizle
(x − 4)(x + 3) ≤ 0 → −3 ≤ x ≤ 4: 8 tam sayı.

Soru 2. (x − 2)²·(x + 1) < 0 eşitsizliğinin çözüm kümesi nedir?

Çözümü gösterÇözümü gizle
(x − 2)² ≥ 0 olduğundan işaret (x + 1)'e bağlı; x = 2'de ifade sıfır: x < −1.

Soru 3. x² + mx + 9 > 0 eşitsizliği her gerçek x için doğruysa m'nin alabileceği kaç tam sayı değeri vardır?

Çözümü gösterÇözümü gizle
a = 1 > 0 ve Δ = m² − 36 < 0 → −6 < m < 6: 11.

Soru 4. x² − 6x + m = 0 denkleminin zıt işaretli iki kökü varsa m için ne söylenir?

Çözümü gösterÇözümü gizle
x₁·x₂ = m < 0: m < 0.

Soru 5. x² − 4 < 0 ve x − 1 > 0 eşitsizlik sisteminin çözüm kümesi nedir?

Çözümü gösterÇözümü gizle
−2 < x < 2 ile x > 1'in kesişimi: 1 < x < 2.
